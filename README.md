# Tidy

**A storage cleaner for Windows that explains everything it shows.**

Other cleaners list folders and sizes and leave you guessing what is safe to delete. Tidy labels every item in plain
words with one of three colours, so beginners can free up space without breaking anything:

- 🟢 **Safe to delete:** junk that Windows and apps make again by themselves (temp files, caches, update leftovers, Recycle Bin).
- 🟠 **Your choice:** your own files, like old videos, downloads, installers and duplicate copies.
- 🔴 **Keep:** Windows and installed programs. Tidy never lets you tick these.

It finds junk, maps every folder, shows large and duplicate files, and lets you move things to the Recycle Bin (can be
undone) or delete them for good. Its other tools clean leftovers of uninstalled apps, free up memory and speed up start-up.

**Download:** the latest **Tidy-Setup.exe** from [Releases](https://github.com/Deba-dev/tidy/releases) (Windows 10 and 11).
It updates itself.
