# Tidy 0.2.1

A small fix for moving the window. Everything from 0.2.0 is included.

## Fixed
- **Drag the window again:** a window size saved while in fullscreen could bring Windowed mode back without a title bar, so it could not be moved. Windowed mode now always has its title bar.
- **Move from Borderless and Fullscreen:** touch the top edge of the screen and drag the new grip (six dots, left of minimize). Tidy pops out into a normal window that follows the mouse.

## Install
Download **Tidy-Setup.exe** below and run it. On 0.2.0, Tidy offers this update by itself.
