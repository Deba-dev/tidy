# Tidy 0.1.0

The first version of Tidy, the storage cleaner that explains.

- Scans your drives and labels everything in plain words: **Safe to delete**, **Your choice** or **Keep**.
- **Junk**: temporary files, Windows Update leftovers, crash reports, browser caches (Chrome, Edge, Brave, Firefox,
  Opera, Vivaldi), app caches (Discord, Spotify, Steam, Epic, VS Code, Teams, Slack, WhatsApp), graphics shader
  caches, thumbnail cache, developer caches, driver installer leftovers, old installers in Downloads, Recycle Bin.
- **Space map**: every folder, biggest first, each with what it is and whether it can go.
- **Large files** and **Duplicates** (only among your own files; one copy always stays).
- Review before deleting: Recycle Bin (can undo) or permanently.
- Windows' protected junk can be cleaned after "Restart as administrator".
- Light and dark look, Windowed / Borderless / Fullscreen, optional tray.
